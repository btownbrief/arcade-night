How it scores

Every game keeps its own board tonight. Each board pays 10, 7, 5, 3, 2 to the top five and 1 to anyone who played. Add them up across the games and the biggest number is Player of the Night. Ties go to whoever played more games, then more firsts.

No account. Your phone is your identity, same as in every Btown game; the name you set in one game is the name on the wall. Ask the host if you'd rather not be shown.
